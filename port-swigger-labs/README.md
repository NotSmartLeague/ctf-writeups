# About 
This directory contains my write-ups for the PortSwigger Web Security Academy Labs.

Link: https://portswigger.net/web-security/all-labs

I created this collection to document my learning journey in web security, since explaining every theoretical concept behind the practice forces me to understand it in depth.

Each write-up includes:

1. A short explanation of the vulnerability
2. The exploitation process
3. The root cause
4. Mitigation strategies

The goal is not just to solve the lab, but to understand why the vulnerability exists and how it can be prevented.
